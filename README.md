## About

I design and build production systems end-to-end: cloud architecture, RESTful &amp; OData APIs, full-stack web applications, and AI/LLM-driven platforms for enterprises in professional services, financial services, and healthcare. Currently at **10Pearls**, leading delivery of AI-assisted workflow automation and enterprise knowledge platforms for global clients.

My work spans the full stack — software architecture and system design, backend engineering in .NET, Python, and Node.js, frontend development with React and Angular, RESTful/OData API design, and cloud infrastructure on Microsoft Azure. In recent years I've focused heavily on applied AI: RAG pipelines, multi-agent orchestration, and LLM-integrated platforms that are grounded, auditable, and enterprise-ready.

Performance, security, and clean architecture are non-negotiable for me — I apply SOLID principles, clean code, and pragmatic design patterns to keep systems maintainable as they grow.

**Core competencies:** Software Architecture & System Design · Backend Development (.NET/Python/Node.js) · Frontend Development (React/Angular) · RESTful & OData API Design · Cloud & DevOps (Azure) · AI/LLM & RAG Engineering · Performance Optimization · Security & Compliance · Team Collaboration & Mentoring
